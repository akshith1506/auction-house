# AuctionHouse

AuctionHouse is a premium online auction platform where collectors, art enthusiasts, and buyers can discover and bid on exclusive items including art, antiques, jewelry, luxury goods, and collectibles.

## Project Overview
This project is a frontend-only auction website built using HTML, CSS, and JavaScript. It includes:
- Home page with hero banner and featured auctions
- Auction listing with filters
- Auction detail modal with countdown timer and bidding
- Registration and login modals
- Bidder dashboard
- Seller dashboard
- About Us page
- Blog page
- Contact Us page
- Dark mode toggle
- Responsive design for desktops, tablets, and mobile devices

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Responsive web design
- No backend required for this internship project

## Live Demo
This project is available in the repository and can be run locally in any browser.
